# My Services - MERN + Tailwind

## Structure

- `client` - React + Vite + Tailwind CSS frontend
- `server` - Node.js + Express + MongoDB backend

## Run frontend

```bash
cd client
npm install
npm run dev
```

## Run backend

Make sure MongoDB is running, then:

```bash
cd server
npm install
npm run dev
```

Frontend: http://localhost:5173  
Backend: http://localhost:5000
